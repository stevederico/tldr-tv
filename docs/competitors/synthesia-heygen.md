# Synthesia & HeyGen

**URLs:** https://www.synthesia.io · https://www.heygen.com  
**Category:** Script → AI avatar talking-head video  
**Last researched:** 2026-07-13

## One-liner

Type a script (or translate one); get a **virtual presenter** video with lip-sync avatars — corporate training and marketing’s default “AI spokesperson.”

## Who it’s for

- L&D / internal training  
- Marketing localization (one script → many languages)  
- Sales enablement without filming humans  

## How it works

1. Write or paste script  
2. Pick stock or custom avatar + voice / clone  
3. Generate talking-head (and scenes/B-roll depending on product)  
4. Edit, brand, export MP4  
5. Enterprise: SSO, shared workspaces, compliance  

**Synthesia** leans enterprise training. **HeyGen** leans marketing + viral avatar/translation features. Both are avatar-first, not article-reader-first.

## Features (relevant)

| Feature | Synthesia | HeyGen |
|---|---|---|
| Script → avatar video | Yes | Yes |
| Custom avatars | Enterprise strength | Strong consumer/pro |
| Translation / dubbing | Yes | Flagship |
| Stock avatars | Large library | Large library |
| API | Yes | Yes |
| Article URL in | Weak / not core | Weak / not core |

## Pricing (order of magnitude 2026)

| | Ballpark |
|---|---|
| Synthesia | Free trial → ~$18–$70+/mo creator; enterprise custom (minutes of video) |
| HeyGen | Free limited → ~$24–$120+/mo; enterprise custom |

Metered by **video minutes** and avatar features.

## Strengths

- Best-in-class **presenter** metaphor  
- Localization at scale  
- Enterprise procurement path  
- High production trust for training  

## Weaknesses / gaps vs us

- Uncanny / avatar aesthetic ≠ essay with chapter art  
- Script is the unit, not “this webpage’s full prose”  
- Expensive for long essays/books (minute pricing)  
- No word-synced original-text reading UX  
- Different emotional product: “training video” vs “watch the article”  

## Overlap with us

| Dimension | Overlap |

| Long-form cost | Their model punishes length; ours can embrace it |

## Implications for us

- Do **not** become an avatar company  
- Users comparing “AI video” may expect faces — education needed: *illustrated audio, not deepfake host*  
- Enterprise training budget is a possible later vertical; not the extension wedge
