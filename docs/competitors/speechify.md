# Speechify

**URL:** https://speechify.com  
**Category:** Listen to any page / consumer TTS (+ expanding into podcasts & video)  
**Last researched:** 2026-07-13

## One-liner

Mass-market text-to-speech that reads web pages, PDFs, books, and docs aloud via apps + browser extension — the default “listen to this” habit for millions.

## Who it’s for

- Students, professionals, accessibility users (dyslexia, ADHD, eye strain)
- Anyone who wants **instant read-aloud** of whatever is on screen
- Expanding into creators via Studio / API / AI Podcasts

Claims 60M+ users (marketing).

## How it works

1. Install mobile app, desktop, or **browser extension**  
2. Open page / PDF / Drive file → press play  
3. AI voice narrates; UI **highlights text** as it reads  
4. Speed up to ~5x (Premium); skip headers/footers  
5. Premium: AI summaries, voice chat about content, **AI Podcasts**, voice typing  

Also: **Speechify Studio** (voiceovers/dubbing) and **Speechify API**.

## Features (relevant)

| Feature | Notes |
|---|---|
| Webpage / PDF / book listen | Core product |

## Pricing (speechify.com/pricing, 2026-07)

| Plan | Price | Notes |
|---|---|---|

| Premium | **$29/mo** (yearly ~60% off → often cited ~$139/yr) | Natural voices, 5x speed, podcasts, chat, integrations |
| Studio / API | Separate pricing pages | Creator / enterprise |

## Strengths

- **Habit ownership**: “listen to this page” is already their job  
- Extension + mobile coverage  
- Highlight-while-speaking trains the interaction model users will expect  
- Brand scale and App Store presence  
- Moving into podcasts/video (category creep toward us)

## Weaknesses / gaps vs us

- **Audio-first**, not illustrated “watch” with chapter images  
- Podcast path is summary/conversation, not full-faithful long-form film  
- No chapter hero / beat-image model  
- Not a curated library of guides with word timings as first-class media  
- Billing complaints in third-party reviews (cancel friction)

## Overlap with us

| Dimension | Overlap |
|---|---|
| Open-web “this page” | **Highest** |
| Listen to articles | **Highest** |
| Text highlight sync | High (they have it; we need word-level + seek) |
| Illustrated / video essay | **Low today** (watch their Studio/video roadmap) |
| Publish/export MP4 | Low–medium |

## Implications for us

1. **Primary consumer competitor** for the extension wedge  
2. Beat them on **visual watch** (images + captions as product, not TTS chrome)  
3. Match or exceed highlight-follow UX or feel worse  
4. Don’t fight on voice count; fight on **fidelity + pictures + player**  
5. Monitor AI Podcasts / video generator — if they ship article→video well, threat spikes
